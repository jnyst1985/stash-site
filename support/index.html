Support Version 1.0

Support

Stash is a link saver for iPhone. You send it a link from any app and it keeps that link with the page title, so you can find it again later. You can tag links, file them into collections, add a note, search everything you have saved, and export the lot as a JSON file. It all lives on your device: no account to make, nothing to sync, no ads.

How it works

Saving a link from any app

  1. Tap the share button In any app that can share a link, Safari and YouTube and Mail included, tap share on the thing you want to keep.
  2. Pick Stash Choose Stash from the row of apps. The first time, you may need to scroll that row to the end, tap More, and switch Stash on.
  3. Tap Done The link is saved the moment the sheet opens. Add tags or file it into a collection right there if you want, then tap Done. Shared the wrong thing? Tap Undo.

Good to know

Three things that surprise people

Titles arrive on their own
A new link shows its URL first, then swaps to the page title once Stash has fetched it. Nothing to tap.
"Already saved"
Stash keeps one copy of a link. Share the same one twice and it tells you when you first saved it instead of making a duplicate.
Exporting
Open COLLECTIONS from the feed, then tap the share icon in the top bar. You get one JSON file with everything you have saved.
