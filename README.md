# stash-site

The public pages for **Stash**, a link saver for iPhone. Everything you save stays on your device.

- Privacy: https://jnyst1985.github.io/stash-site/privacy/
- Support: https://jnyst1985.github.io/stash-site/support/

Static HTML served by GitHub Pages from `main`. No build step.
